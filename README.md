# usm-proyecto
Aplicacion web que buscara ayudar a las personas a ver opciones de empleo a su alrededor, y poder postular sin necesidad de tener experiencia previa. Tambien las empresas podran buscar trabajadores colocando "pines" en los lugares donde necesiten trabajadores
